# How to Localize JASM

This guide explains how to add or update a locale for JASM using the CSV-based translation workflow.

## File Layout

```
src/GIMI-ModManager.WinUI/Strings/
  en-us/
    Resources.resw    ← Source of truth (851 entries, English with context comments)
  es/
    Resources.resw    ← Spanish (822 entries)
    Settings.resw     ← Settings page strings (24 entries)
    Startup.resw      ← Startup page strings (13 entries)
  pt-br/
    ...
  zh-cn/
    ...
  ru-ru/
    ...
```

## Translation Template

The master translation template is at `C:/temp/translation_template.csv` (generated by `_scripts/generate_csv.py` — not in the repo; regenerate as needed). It contains:

| Column | Description |
|--------|-------------|
| Key | The internal identifier (matches resw `data name`) |
| English | The English source text |
| Context Comment | Explains where this string appears and what it means |
| Spanish (reference) | Spanish translation for tone/style guidance |
| Portuguese (Brazil) | Empty — fill with translations |

To regenerate the template from en-us:

```bash
python _scripts/generate_csv.py
```

This scans `en-us/Resources.resw` and produces `C:/temp/ptbr_translations.csv`.

## Workflow: Adding a New Locale

### Step 1: Split into batches

```bash
python _scripts/split_batches.py
```

Splits the master CSV into batches of 15 rows each, saved to `C:/temp/ptbr_batches/`.

### Step 2: Translate each batch

For each batch CSV (e.g. `ptbr_batch_01.csv`), fill the last column ("Portuguese (Brazil)") with translations. Use the **Context Comment** to understand where each string appears:

```csv
Key,English,Context Comment,Spanish (reference),Portuguese (Brazil)
CharactersPage_Start3Dmigoto.Content,Start 3Dmigoto,"Button label to launch the 3DMigoto model importer process",Iniciar 3Dmigoto,Iniciar 3Dmigoto
```

Rules for translation:
- Keep `{0}`, `{1}` placeholders exactly as they appear
- Keep `{{TargetPath}}` and other template tags intact
- Keep URLs and file paths unchanged
- Keep brand names (GameBanana, JASM) unchanged
- Use the Spanish column as tone/style reference

### Step 3: Apply translations

```bash
python _scripts/apply_csv.py
```

Reads all batch CSVs from `C:/temp/ptbr_batches/` and writes the translated values back to `pt-br/Resources.resw`.

### Step 4: Handle Settings.resw and Startup.resw

These files contain strings that exist in per-locale files but NOT in en-us/Resources.resw. They must be translated separately using the same CSV workflow:

```bash
# Generate Settings CSV from en-us (using XAML hardcoded text as English source)
python _scripts/generate_settings_csv.py

# Generate Startup CSV
python _scripts/generate_startup_csv.py

# Split, translate, apply (same as Steps 1-3 above)
```

### Step 5: Build and test

```bash
dotnet build src/GIMI-ModManager.WinUI/GIMI-ModManager.WinUI.csproj -p:Platform=x64
start "" "src/GIMI-ModManager.WinUI/bin/x64/Debug/net9.0-windows10.0.22621.0/JASM - Just Another Skin Manager.exe"
```

Navigate through the app to verify translations appear correctly.

## Critical Rules for Key Naming

The app uses two different key resolution mechanisms that require different formats:

### C# `GetLocalizedStringOrDefault` → underscore format

In ViewModel/Service C# code:
```csharp
localizer.GetLocalizedStringOrDefault("CharDetails_DeleteDialog_Content")
```

The resw key must use underscores: `CharDetails_DeleteDialog_Content`

**Dots break this lookup.** If the key has a dot (e.g. `CharDetails_DeleteDialog.Content`), the localizer will fail silently and return the English fallback.

### XAML `l:Uids.Uid` → dot format

In XAML:
```xml
<Button Content="Run" l:Uids.Uid="CharacterDetails_RunCommandButton" />
```

WinUI3Localizer resolves this as `CharacterDetails_RunCommandButton.Content` (appends property with dot).

The resw key must use dot format: `CharacterDetails_RunCommandButton.Content`

### How to know which format to use

| Usage | Format | Example resw key |
|-------|--------|-----------------|
| C# `GetLocalizedStringOrDefault("Key")` | underscore | `CharDetails_DeleteDialog_Content` |
| XAML `l:Uids.Uid="Key"` on element | dot (Key.Property) | `CharacterDetails_RunCommandButton.Content` |
| Code-behind setting property directly | underscore | `MyTextBox.PlaceholderText = localizer.GetLocalizedStringOrDefault("Key_PlaceholderText")` |

## Common Issues

### String shows in English despite being in resw

Check the key format — if it's used in C# with `GetLocalizedStringOrDefault`, ensure the resw key uses underscores, not dots.

### PRI210 build error

The app is still running. Kill it first:
```powershell
Get-Process -Name 'JASM*' | Stop-Process -Force
```

### "root node not found" build error

The resw XML is corrupted. Verify it has exactly one `</root>` at the end and no duplicate entries:
```bash
grep -c '</root>' Strings/pt-br/Resources.resw  # Should return 1
```
